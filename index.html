📖 How It Works

🎥

1. Camera Feed

Captures frames at FRAME_CHECK_SECONDS intervals from your webcam.

📊

2. Change Detection

Compares pixel differences. If score > MIN_CHANGE_SCORE, triggers AI.

🧠

3. Local Qwen

Sends frame to MODEL via API_URL. 100% offline, private.

⏱️

4. Cooldown

Waits VISION_COOLDOWN_SECONDS before next analysis to save resources.

🔑 Quick Setup

Get the local AI running in 3 minutes.

🧠 Install Local Qwen 3.5:4b

  1. Install Ollama from ollama.com.
  2. Open terminal and run: ollama pull qwen3.5:4b
  3. Start the server: ollama serve
  4. Open the Config tab to tune parameters.
  5. Serve this HTML via python -m http.server 8000 to avoid CORS.
